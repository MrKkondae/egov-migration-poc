# egov-migration-poc

전자정부프레임워크 3.x → 4.3 전환 PoC 저장소입니다.

## 목적

- 전자정부프레임워크 3.x 기반 소스를 4.3 기준으로 분석/변환/검증하는 절차를 정리한다.
- Qwen Coder를 활용한 분석 및 변환 프롬프트를 관리한다.
- Codex를 활용한 검토 프롬프트와 검토 결과를 관리한다.
- 실제 전환 사업 투입 전 폐쇄망 환경에서도 재현 가능한 절차를 확보한다.

## 기본 절차

1. 전환 정책 수립
2. 현행 소스 분석
3. 자동 변환 대상 식별
4. 변환 프롬프트 실행
5. 컴파일 및 오류 분석
6. 검증 결과 반영
7. 반복 개선
